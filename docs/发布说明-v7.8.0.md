# AgentPrimordia v7.8.0 发布说明

**发布日期**：2026-10-29
**版本**：v7.8.0（累计包含 v7.6 / v7.7 / v7.8 三批工作）

## 一句话

这是一次**累计发布**：把已经完成但未单独发版的 7.6「第一印象」、7.7「A2A 楔子」、7.8「8.0 彩排」三批内容，连同 2026-10-26 安全加固批次，一起以 7.8.0 对外发布。

> 7.6 / 7.7 为什么不单独发？三批提交在时间线上交错，无法回溯成内容干净的独立 semver tag。`batch/v7.6`、`batch/v7.7` 保留为非发布标记，仅供历史定位，不影响 Go proxy。详见 [`docs/版本状态-v7.6-v7.8.md`](版本状态-v7.6-v7.8.md)。

## 你会得到什么

- **更容易开始**：英文 README / getting-started，`ap init` 后无需 API key 即可跑通真实 ReAct 循环（Demo 模式）。
- **更硬的契约**：pkg 导出符号黄金快照冻结，新增公共导出会直接让 CI 变红。
- **能跑的互操作**：A2A 跨进程委托 demo（发现→委托→轮询→取回→取消），零凭据约 5 秒，协议符合性 8/8。
- **可验证的供应链**：WASM 工具签名 → 公钥钉扎 → 验签 → wazero 沙箱执行，四类拒绝分支都有实证。
- **8.0 的脚手架**：387 个导出符号标注 `v8.0-cut`，`ap migrate` 可机械重写 import 路径。
- **默认更安全**：Shell 路径 jail、MCP/A2A loopback 默认、流式与并发缺陷修复。

## 升级前注意

1. `NewShell()` 默认只允许当前工作目录；跨目录请显式 `WithAllowedWorkdirs`。
2. A2A Server 默认只接受 loopback；跨机必须配置 `WithAuth` / `WithGRPCAuth`，同机反代也要显式认证。
3. MCP Server 未配 APIKey 时拒绝非 loopback；跨机必须 `WithAPIKey`。
4. TS SDK 升级到 zod 4 / vitest 5。

## 安装

```bash
go install github.com/Gleamseekers/AgentPrimordia/v7/agentprimordia/cmd/ap@v7.8.0
ap version   # 7.8.0
```
