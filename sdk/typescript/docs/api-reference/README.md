# API Reference

## 语言

| 语言 | 包名 | 包管理器 |
|------|------|---------|
| TypeScript | `@synth/sdk` | npm |
| Go | `github.com/Mirelth/Synth` | go modules |
| Python | `synth` | pip |
| Java | `com.synth` | gradle/maven |
| Rust | `synth` | cargo |
