# 配置护栏（Configure Guardrail）

本指南介绍如何为 Agent 配置输入/输出护栏规则。

## 基本配置

```go
import synth "github.com/Mirelth/Synth/v7/synth/pkg"

// 创建护栏引擎
engine := synth.NewGuardrailEngine()

// 添加 Prompt 注入检测（优先级最高）
engine.AddRule(synth.NewPromptInjectionRule(synth.PromptInjectionConfig{}))

// 添加 PII 脱敏规则
engine.AddRule(synth.NewPIIRule(synth.PIIRuleConfig{}))

// 注入 Agent：通过 WithInputGuard 传入护栏检查函数，
// 用户输入进入 ReAct 循环前自动检查
agent, err := synth.NewAgent("my-agent", "You are a helpful assistant.", provider,
    synth.WithInputGuard(func(content string) (string, bool, error) {
        report, err := engine.Check(content, synth.CheckInput)
        if err != nil {
            return content, false, err
        }
        if !report.Passed {
            return content, true, nil // blocked=true 拒绝该输入
        }
        return content, false, nil
    }))
```

## 自定义规则

实现 `Rule` 接口即可创建自定义规则：

```go
type MyRule struct{}

func (r *MyRule) Name() string { return "my-rule" }
func (r *MyRule) Priority() int { return 200 }

func (r *MyRule) Check(input string, cp synth.GuardrailCheckPoint) (*synth.GuardrailResult, error) {
    if containsForbidden(input) {
        return &synth.GuardrailResult{
            RuleName: "my-rule",
            Action:   synth.GuardrailReject,
            Severity: synth.SeverityHigh,
            Message:  "包含禁止内容",
        }, nil
    }
    return &synth.GuardrailResult{RuleName: "my-rule", Action: synth.GuardrailPass}, nil
}
```

## 主题约束

限制 Agent 只处理特定主题：

```go
topicRule := synth.NewTopicConstraintRule(synth.TopicConstraintConfig{
    Topics: []string{"编程", "技术", "科学"},
})
engine.AddRule(topicRule)
```

## 敏感词过滤

基于 Trie 树的高效敏感词匹配：

```go
trieRule := synth.NewSensitiveWordRule(synth.SensitiveWordConfig{
    Words: []string{"敏感词1", "敏感词2"},
})
engine.AddRule(trieRule)
```

## 检查点说明

- `CheckInput`：在 Agent 处理用户输入前检查
- `CheckOutput`：在 Agent 返回响应前检查

规则按优先级降序执行，遇到 `GuardrailReject` 立即终止。
